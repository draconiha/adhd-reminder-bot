# Тестирование ADHD Reminder Bot без остановки боевого бота

## 1. Боевой бот

Боевой бот остаётся на VDSina в:
`/root/adhd-reminder-bot`

Его токен хранится только в локальном `config.py` на сервере и не попадает в GitHub.

## 2. Тестовый бот

Создай второго Telegram-бота через @BotFather.

Для тестового бота нужен отдельный токен. Не вставляй его в GitHub.

На компьютере сделай отдельную копию репозитория:

```powershell
git clone https://github.com/draconiha/adhd-reminder-bot.git adhd-reminder-bot-test
cd adhd-reminder-bot-test
```

Создай рядом с `bot.py` файл `config.py`:

```python
BOT_TOKEN = "ТОКЕН_ТЕСТОВОГО_БОТА"
```

Создай окружение и установи зависимости:

```powershell
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Запуск:

```powershell
python bot.py
```

Тестовый бот использует отдельный `tasks.db`, поэтому его данные не смешиваются с боевыми.

## 3. Как работать с кодом

- `main` — версия для боевого бота.
- `dev` — текущая тестовая версия.
- Новые функции сначала проверяются на тестовом боте.
- После проверки изменения можно перенести в `main`.

Не запускай два процесса с одним и тем же Telegram-токеном через polling одновременно.

## 4. Обновление боевого бота

Когда версия из `dev` проверена:

```bash
cd /root/adhd-reminder-bot
git checkout main
git pull
systemctl restart adhd-bot
systemctl status adhd-bot --no-pager
```

Логи:

```bash
journalctl -u adhd-bot -n 50 --no-pager
```

Перезапуск занимает несколько секунд. Саму разработку при этом можно продолжать на тестовом боте.

## 5. 24/7 через systemd

Файл сервиса находится в `deploy/adhd-bot.service`.

На сервере:

```bash
cp /root/adhd-reminder-bot/deploy/adhd-bot.service /etc/systemd/system/adhd-bot.service
systemctl daemon-reload
systemctl enable --now adhd-bot
systemctl status adhd-bot --no-pager
```

Если бот уже запущен вручную, сначала останови старый процесс, чтобы два экземпляра не использовали один токен.

## 6. Что сейчас тестируем

В `dev` добавлены:

- время напоминаний по умолчанию с 00:00 до 23:00;
- ежедневная сводка дел в пользовательское время по умолчанию;
- сообщение «Сегодня отдыхаем!» при отсутствии дел;
- кнопка «✅ Сделано» прямо в напоминании;
- более понятное уведомление, если время дела уже прошло;
- «📥 Куча дел» для задач без даты;
- разбор дела из кучи в календарь с выбором даты, времени и предварительного напоминания;
- первичная настройка времени подъёма и сна;
- защита от повторного ответа на один callback;
- исправление уведомлений за день до задачи;
- подготовка к запуску через systemd.
